\chapter{Сбор данных}
Для решения задачи распознавания возраста человека по фотографии лица был проведён анализ доступных открытых наборов данных (датасетов), содержащих изображения лиц с аннотированным возрастом.  


\section*{Публичные датасеты}
В рамках работы используются и рассматриваются следующие открытые датасеты:
\begin{itemize}
	\item UTKFace;
	\item APPA-Real Age;
\end{itemize}
\subsection*{UTKFace}
UTKFace - один из наиболее распространённых наборов данных для задач оценки возраста и пола.  
Он содержит более 20\,000 изображений лиц людей в возрасте от 0 до 116 лет, снятых в различных условиях освещения, ракурсах и с разным фоном.  \cite{zhifei2017cvpr}
Каждое изображение имеет аннотацию, закодированную непосредственно в названии файла в формате:
\begin{center}
	\smallcode{[age]\_[gender]\_[race]\_[date\_time].jpg}
\end{center}
\begin{itemize}
	\item \smallcode{age} — возраст человека (целое число);
	\item \smallcode{gender} — пол (0 — мужчина, 1 — женщина);
	\item \smallcode{race} — этническая принадлежность (0–4, пять категорий);
	\item \smallcode{date\_time} — метка времени.
\end{itemize}

Изображения имеют размер: 200 на 200 пикселей.

\subsection*{APPA-Real Age}
APPA-Real Age - содержит 7591 изображение с указанием реального и предполагаемого возраста. Общее количество предполагаемых голосов составляет около 250 000. В среднем на каждое изображение приходится около 38 голосов, что делает средний предполагаемый возраст очень стабильным (0,3 стандартной ошибки от среднего значения). \cite{agustsson2017appareal}

Каждое изображение имеет порядковый номер, а реальный возраст указан в отдельном \smallcode{csv} файле: 
\begin{itemize}
	\item \smallcode{image name} — порядковый номер изображения;
	\item \smallcode{real\_age} — реальный возраст;
	\item \smallcode{apparent\_age} — воспринимаемый возраст;
\end{itemize}


Изображения имеют различный размер.\\
В данной работе будем использовать только метки реального возраста.

\chapter{Предобработка данных}
Для выбранных датасетов будут выполнены следующие шаги для приведения данных к единому виду:
\begin{enumerate}
	\item Загрузка данных из открытых источников.
	\item Конкатенация датасетов с консистентным именем файла: \smallcode{image\_[number]\_[real\_age].jpg}
	\item Создание \smallcode{csv}-файла с метками для изображений.
	\item Приведение изображений к единому размеру.
	\item Разбиение на тестовую, валидационную и тестовые подвыборки.
\end{enumerate}

\subsection*{Разделение датасета на подвыборки}
Для разделения полученнго датасета на \smallcode{test, train, valid}-подвыборки был реализован скрипт на языке \smallcode{Python} \cite{cnn-age-recognize-splitter}


Скрипт делит выборку целиком на $K$ квантилей и равномерно забирает данные для подвыборок в соотношении:
\begin{itemize}
	\item train: 70\%;
	\item validation: 20\%;
	\item test: 10\%;
\end{itemize}

В результате сбора и предварительной обработки данных был получен датасет размером 31299. Каждое изображение приведено к единому размеру 224 на 224 пикселя. Создан \smallcode{csv}-файл с метками для каждой фотографии лица.

\chapter{Оценка качества модели}
При выборе метрик оценки качества модели учитываем следующие факторы:
\begin{itemize}
	\item непрерывный характер целевой переменной (возраст);
	\item интерпретируемость ошибки в годах;
	\item наличие неравномерного распределения возрастов в датасете;
	\item прецеденты в похожих задачах \cite{app151810212}
\end{itemize}


\chapter{Реализация модели}
В основе реализованной модели лежит подход использующий сверточные нейронные сети (Convolutiobal Neural Network, CNN). использование CNN является обоснованным, поскольку входные данные представлены изображениями, для которых сверточные архитектуры демонстрируют существенно более высокую эффективность за счёт автоматического извлечения признаков.
\subsubsection*{Программная реализация}
Для программной реализации взята предобученная модель ResNet-50 (Предобученные веса: ImageNetV2).


Исходная модель ResNet-50 модифицирована заменой "головы" нейронной сети на регрессию:
\begin{itemize}
	\item Полносвязного слоя (2048 в 512) - формирование компактного представление признаков;
	\item Функции активации ReLU - обеспечивает нелинейность модели;
	
	\item Dropout - применяется для регуляризации и снижения переобучения;
	
	\item Выходного линейного слоя - формирует скалярное предсказание возраста.
\end{itemize}


Обучение модели проводилось с использованием функции потерь MSE и оптимизатора Adam на обучающей выборке.

Значения гиперпараметров были выбраны эмпирически, после чего обучение проводилось с контролем качества на валидационной выборке и сохранением наилучшей модели.

\chapter{Результаты}

Полученная модель дает ошибку MAE (ошибка семантически интерпретируется в годах):
\[
\operatorname{MAE}=5.102;
\]

Полученное значение MAE свидетельствует о том, что в среднем предсказанный возраст отличается от истинного примерно на 5 лет, что является типичным результатом для задач оценки возраста по изображению лица.


Для более детального анализа качества модели был выполнен разбор ошибки MAE по возрастным группам, что позволяет выявить зависимость точности модели от возрастной группы.

Ошибки по бинам представлены на \hyperref[fig:bean-mae]{Рисунке \ref*{fig:bean-mae}} приведен пример наивной нормализации изображения до заданного знчений.
\begin{figure}[h!]
	\centering
	\includegraphics[width=1\linewidth]{../artifacts/mae_barplot.png}
	\caption{Пример сжатия изображения из датасета APPA}
	\label{fig:bean-mae}
\end{figure}

Наименьшее значение MAE достигается для младших возрастных групп (0–10 лет), тогда как для пожилых возрастов ошибка существенно возрастает. Это объясняется малым числом обучающих примеров в старших возрастных группах и высокой визуальной вариативностью внешности людей пожилого возраста.


Большая ошибка для возрастной группы 70+ коррелирует с уменьшением числа примеров в данной категории, что указывает на влияние дисбаланса данных на итоговое качество модели.
